# AvaloniaThemeLab.Minimal

An example app with its own small theme built on [AngelSix.ThemeEngine](https://www.nuget.org/packages/AngelSix.ThemeEngine). It starts from `dotnet new avalonia.mvvm`, removes Fluent, and adds a theme that uses the engine's main features. It does not reference `AngelSix.Themes.Default`.

## What is here

| File | What it does |
|---|---|
| `Theme/MinimalTheme.cs` | The theme: one class, derived from `ThemeBase`, that `App.axaml` includes as `<theme:MinimalTheme />` in place of Fluent. It loads every file in `Controls/`. Its tokens: colour seeds become full ramps (`[ColorRamp]`) and hues a control can pick (`[AccentHue]`). Roles (`[AccentRole]`) name the stage each part uses. Sizes are ladders on one `BaseSize` (`[SizeScale]`). |
| `Controls/Button.axaml`, `Controls/Window.axaml` | The only two styled controls. Every value is a token. |
| `App.axaml.cs` | Builds the dependency injection container: registers the app's one theme as `MinimalTheme.Current` (generated by the engine), and the window's view model. It implements `IServiceHost`, so `Design.DataContext="{DesignContext}"` gives the designer the view model a view's `x:DataType` names, from the same container. |
| `ViewModels/MainWindowViewModel.cs` | Takes the theme through its constructor. Its `[Command]` methods switch dark mode and change `BaseSize`, and every control follows live. |
| `Views/MainWindow.axaml` | Buttons for those commands, and two buttons with an accent hue (`theme:Accent.Kind`). |

## No Fluent

A control with no `ControlTheme` in `Controls/` has no template, so it shows nothing. To style another control, add a file for it in `Controls/`; there is no list to update.

## Making it yours

- Change a seed colour and its whole ramp follows.
- Add a hue: one more `[AccentHue, ColorRamp]` colour, then use it with `theme:Accent.Kind`.
- Need a new value? Add a property to `MinimalTheme` and read it as `{color:...}`, `{size:...}` or `{theme:...}`.
