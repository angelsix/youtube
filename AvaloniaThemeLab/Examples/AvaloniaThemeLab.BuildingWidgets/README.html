Overview

What you are building

A complete Avalonia 12 widget gallery built from scratch using DefaultTheme, a custom [IconGallery], and AngelSix.Mvvm. You will create the project from zero, wire DI and a live gallery toolbar, and build seven reusable UserControls — from a glowing Light/Dark Weather card to a full collapsible App Shell and Theme Settings panel.

What you will build in order1. ExampleContent (first runnable checkpoint) → 2. MoonWidget (Weather card) → 3. SideNav, 4. TopMenu & 5. AppShell → 6. ModeToggle & 7. ThemeSettings (plus popout ThemeSettingsWindow).

Phase 1 · Project & Packages

Create the project from scratch

Start from a clean dotnet new avalonia.mvvm app, remove Fluent and the template Inter font package, and install the Theme Engine, Default Theme, MVVM, and DI packages.

  1. First we scaffold a fresh Avalonia desktop project and solution so we have a clean workspace to build our widget gallery in.

    dotnet new avalonia.mvvm -n MyWidgetsApp
dotnet new sln -n MyWidgetsApp --format sln
dotnet sln MyWidgetsApp.sln add MyWidgetsApp/MyWidgetsApp.csproj

    Open MyWidgetsApp.sln in Rider rather than opening the folder so Rider loads the theme engine's live templates from .DotSettings.

  2. Because we're styling every widget with the AngelSix Theme Engine and AngelSix.Mvvm, we remove Avalonia's Fluent2Theme (or FluentTheme on older templates), the Inter font package, and CommunityToolkit.Mvvm so nothing competes with our theme or MVVM base classes.

    dotnet remove MyWidgetsApp package Avalonia.Themes.Fluent2
dotnet remove MyWidgetsApp package Avalonia.Themes.Fluent
dotnet remove MyWidgetsApp package Avalonia.Fonts.Inter
dotnet remove MyWidgetsApp package CommunityToolkit.Mvvm

    Newer Avalonia 12 templates reference Avalonia.Themes.Fluent2 while older ones reference Avalonia.Themes.Fluent — remove whichever is in your .csproj. Removing CommunityToolkit.Mvvm ensures ViewModelBase and ObservableObject resolve to AngelSix.Mvvm. AngelSix.Themes.Default styles every Avalonia control directly and brings its own Inter font package (AngelSix.ThemeEngine.Fonts).

  3. Next we install DefaultTheme, ThemeEngine, Mvvm, and Dependency Injection so we can build custom icons, bindable ViewModels, and themed controls.

    dotnet add MyWidgetsApp package AngelSix.Themes.Default
dotnet add MyWidgetsApp package AngelSix.ThemeEngine
dotnet add MyWidgetsApp package AngelSix.Mvvm
dotnet add MyWidgetsApp package Microsoft.Extensions.DependencyInjection

  4. Before adding our own code, we clear out the template's unused ViewModelBase, MainViewModel, and ViewLocator and drop .WithInterFont() so the project stays clean and minimal.

    Delete the template's unused ViewModels/ViewModelBase.cs, ViewModels/MainViewModel.cs, and ViewLocator.cs (we will map ViewModels to widgets cleanly via Window.DataTemplates), then remove .WithInterFont() from Program.cs.

public partial class App : Application
public partial class App : Application, IServiceHost
{
    private ThemeSettingsWindow? _settingsWindow;

    public IServiceProvider Services { get; private set; } = null!;

    public override void Initialize()
    {
        AvaloniaXamlLoader.Load(this);
        Services = BuildServices();
    }

    public override void OnFrameworkInitializationCompleted()
    {
        if (ApplicationLifetime is IClassicDesktopStyleApplicationLifetime desktop)
        {
            desktop.MainWindow = new MainWindow { DataContext = new MainViewModel() };
        }
            desktop.MainWindow = new MainWindow { DataContext = Services.GetRequiredService<MainWindowViewModel>() };

        base.OnFrameworkInitializationCompleted();
    }

    private IServiceProvider BuildServices()
    {
        var services = new ServiceCollection();
        services.AddSingleton(PrototypeTheme.Current);
        services.AddSingleton<Action>(OpenSettingsWindow);

        services.AddTransient<ExampleContentViewModel>();
        services.AddTransient<TopMenuViewModel>();
        services.AddTransient<SideNavViewModel>();
        services.AddTransient<AppShellViewModel>();
        services.AddTransient<MoonWidgetViewModel>();
        services.AddTransient<ModeToggleViewModel>();
        services.AddTransient<ThemeSettingsViewModel>();
        services.AddSingleton<MainWindowViewModel>();

        return services.BuildServiceProvider();
    }

    private void OpenSettingsWindow()
    {
        if (_settingsWindow is { IsVisible: true }) { _settingsWindow.Activate(); return; }

        _settingsWindow = new ThemeSettingsWindow { DataContext = Services.GetRequiredService<ThemeSettingsViewModel>() };
        _settingsWindow.Closed += (_, _) => _settingsWindow = null;
        if ((ApplicationLifetime as IClassicDesktopStyleApplicationLifetime)?.MainWindow is { } owner)
            _settingsWindow.Show(owner);
        else
            _settingsWindow.Show();
    }
}
